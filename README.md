# Arcwise v0.1

Офлайн Android-приложение для локального учёта покупок и продаж рублёвых акций по двум счетам. Kotlin, Jetpack Compose, Room, DataStore. Минимальная версия — Android 8.0 (API 26).

## Запуск

Откройте корневую папку в Android Studio, выберите JDK 17 и установите Android SDK 34 / Build Tools 34.0.0. Gradle Wrapper включён в проект.

На Windows с установленной Android Studio:

```powershell
.\scripts\build.ps1 -Mode debug
.\scripts\build.ps1 -Mode debug -Install
.\scripts\build.ps1 -Mode check
```

Если Studio или SDK находятся в другом месте, задайте `JAVA_HOME` и `ANDROID_HOME`. `JAVA_HOME` должен указывать на JDK 17, а не на системную Java 8. Исходная папка содержит кириллицу, поэтому включён `android.overridePathCheck`.

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Готовая проверенная сборка: `artifacts/Arcwise-v0.1.0.apk`. Снимки экранов находятся в `artifacts/screenshots`, результаты проверки — в `artifacts/verification.txt`. На эмуляторе Android 15 в авиарежиме прошли 4 unit-теста и 2 инструментальных теста; lint завершился без ошибок. Отдельно проверен холодный запуск с сохранёнными данными. Проверка на физическом телефоне ещё требуется.

## Реализованный сценарий

- Демовход без регистрации; при первом входе доступны два пустых счёта.
- Обзор: число счетов, число открытых позиций и затраты по открытым позициям.
- Портфель: все счета или отдельный счёт, объединение одинаковых тикеров, карточка позиции и журнал.
- Покупка и продажа: тикер, счёт, целое количество, ручная цена в рублях. Тикер приводится к верхнему регистру. Цена вводится с точностью до копейки.
- Продажа сверх остатка на выбранном счёте отклоняется; закрытая позиция исчезает, журнал сохраняется.
- Локальный шаблонный ассистент с пометкой «Демо».
- Переименование счетов, светлая и тёмная темы, выход с сохранением операций.

Оформление основано на обоих PNG из `design`: градиенты, полупрозрачные карточки, фирменный знак и нижняя навигация. Функции из макетов вне спецификации v0.1 не включены.

## Расчёты и хранение

Room хранит счета и неизменяемый журнал сделок. Проверка остатка и запись продажи выполняются в одной транзакции. DataStore хранит тему и демосеанс. Выход не удаляет журнал. Резервное копирование Android отключено; удаление приложения удаляет локальные данные.

Цены хранятся целыми копейками. Затраты после частичных продаж представлены точными рациональными дробями на `BigInteger`. Промежуточные расчёты не округляются; округление до двух десятичных знаков выполняется при отображении. Общая средняя взвешивается по оставшимся бумагам на счетах. Сумма затрат не является рыночной стоимостью портфеля.

У приложения нет сетевых разрешений, сервера, внешней модели и аналитических SDK.

## Проверки

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

Для второго запуска нужен эмулятор или подключённый Android. `AcceptanceTest` рассчитан на чистые данные приложения и проходит покупки 2 × 1 000 ₽ и 3 × 1 100 ₽, фильтры, отклонённую продажу, продажу одной бумаги, тему, чат, переименование и повторный вход. Он сохраняет снимки экранов в `Android/data/ru.arcwise.app/files/screenshots` на эмулированном накопителе. `StorageTest` проверяет журнал после закрытия и открытия базы. Unit-тесты покрывают средние 1 060 ₽ / 1 075 ₽, дробные остаточные затраты и неверный ввод.

Для проверки подписанного release APK используйте `:app:connectedReleaseAndroidTest -PtestBuildType=release`.

## Подписанный APK

Локальный ключ релиза находится в `.signing/arcwise-release.jks`, настройки — в `signing.properties`; оба исключены из Git. Сохраните отдельную надёжную резервную копию ключа и пароля: этот ключ нужен для последующих обновлений приложения.

При новой настройке используйте `signing.properties.example` как шаблон. Release собирается с этим ключом, без подмены debug-подписью:

```powershell
.\scripts\build.ps1 -Mode release
```

Результат: `app/build/outputs/apk/release/app-release.apk`. Установки с разными ключами (debug и release) не обновляют друг друга.

## Карточка RuStore

Название: **Arcwise**.

Краткое описание: **Локальный учёт сделок и сводка портфеля по нескольким счетам.**

Описание: Arcwise помогает учитывать покупки и продажи рублёвых акций на двух локальных счетах. Добавляйте сделки вручную, смотрите остатки и среднюю цену по каждому счёту или в общей сводке, просматривайте историю операций. Доступны светлая и тёмная темы и демонстрационный помощник. Приложение работает офлайн; данные хранятся на устройстве. Рыночные котировки, синхронизация и внешний ИИ не предусмотрены.

Для публикации потребуется указать контакт разработчика в кабинете RuStore, загрузить иконку и минимум три снимка из проверенного APK. Публикация через аккаунт разработчика в рамках реализации не выполняется.
